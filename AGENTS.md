# Pi agent tool guard

This is an extension for Pi coding agent which introduces guardrails for executing tools.

## Tech stack

- standard TypeScript module
- tsc for linting

## Code style

- follow clean code principles
- keep focus on code maintenability

## Verification

Linting `npm run lint` must pass.

## Setup

Run `npm run pi-setup` to install the extension into pi's user-level extension folder (`~/.pi/agent/extensions/`), where it is auto-discovered for all projects.
